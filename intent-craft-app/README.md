# IntentCraft app

React + TypeScript + Vite. Turns a spoken or written thought into confirmed decisions and a task package for a coding agent.
See `../CLAUDE.md` for the rules and `../HANDOFF.md` for status.

    npm install
    npm test          # node --test tests/
    npm run lint
    npm run build
    npm run dev       # development server, http://localhost:5173

The always-on copy is `intentcraft.service` at http://127.0.0.1:4173.
